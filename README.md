# 🦙 Llama Capital

Llama Capital is an AI-assisted investment research platform designed around independent research departments rather than a single chatbot.

The system focuses on:

- Opportunity Discovery
- Universe Screening
- Structured Research Reports
- Deterministic QA
- Explainable investment workflows
- Portfolio decision support

## Current Status

🚧 Early prototype

Implemented:

- Domain models
- Opportunity pipeline
- Research reports
- Deterministic QA
- Scoring engine
- Unit tests

## Architecture

```
Opportunity
        │
        ▼
Opportunity Agent
        │
        ▼
Research Report
        │
        ▼
QA
        │
        ▼
Pipeline
```

More departments will be added over time:

- Universe Screener
- Trend Intelligence
- Investment Committee
- Portfolio Builder
- Monitoring
- Dashboard
